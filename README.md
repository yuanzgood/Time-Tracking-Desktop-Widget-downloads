# 时间记录桌面小部件

轻量的 Windows 桌面时间记录工具，支持多任务计时、数据统计、桌面浮窗与个性主题。

[下载最新版本](https://github.com/yuanzgood/Time-Tracking-Desktop-Widget-downloads/releases/latest)

## 使用

推荐下载发行页中的 `Setup-win-x64.exe` 安装版，按向导选择安装位置和是否创建桌面快捷方式。也可以下载 `compact-win-x64.zip` 便携版，解压后双击 `TimeTracker.exe`。两种版本都无需额外安装 .NET。

内置默认简洁、春夏秋冬主题，以及小圆球、男女人物浮窗。更多主题和角色可以在软件设置中分别下载，安装后离线使用，也支持导入素材 ZIP。在线下载需要能够访问 GitHub。

程序、`data` 计时数据、`personalization` 下载素材保存在同一目录。升级前退出旧版，备份并保留这两个文件夹。安装版默认保留卸载后的个人数据。已使用 2.0.0 的用户请升级到新版本，以使用此处的素材下载服务。
