# 时间记录桌面小部件

轻量的 Windows 桌面时间记录工具，支持多任务计时、数据统计、桌面浮窗与个性主题。

[下载最新版本](https://github.com/yuanzgood/Time-Tracking-Desktop-Widget-downloads/releases/latest)

## 使用

下载发行页中的 Windows ZIP，解压后双击 `TimeTracker.exe`，无需安装 .NET。

内置默认简洁、春夏秋冬主题，以及小圆球、男女人物浮窗。更多主题和角色可以在软件设置中分别下载，安装后离线使用，也支持导入素材 ZIP。在线下载需要能够访问 GitHub。

升级前退出旧版，保留原有的 `data` 和 `personalization` 文件夹。已使用 2.0.0 的用户请升级到 2.0.1 或更新版本，以使用此处的素材下载服务。
